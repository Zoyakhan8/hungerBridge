# HungerBridge 🌉

HungerBridge is a smart food donation platform designed to connect food donors with verified NGOs while ensuring food safety during transportation. The project aims to reduce food waste, improve transparency, and make food distribution safer through an IoT-enabled **ZeroWaste Box**.

> **Current Status:** Landing Page UI Completed 🚧
> The application is currently in the frontend development phase. Only the responsive landing page has been developed.

---

## Features

* ✨ Modern and responsive landing page
* 🎨 Glassmorphism-inspired UI
* 🌟 Ambient animated particle background
* 📱 Responsive layout
* ⚡ Built with React and Vite
* 🎬 GSAP-powered animations
* 🎯 Timeline and feature showcase sections

---

## Project Vision

HungerBridge addresses two major problems:

* Food waste from restaurants, bakeries, caterers, and households
* Food insecurity among vulnerable communities

The platform connects donors with verified NGOs while providing transparent and safe food transportation using an IoT-enabled ZeroWaste Box.

---

## ZeroWaste Box

The ZeroWaste Box is the core innovation of HungerBridge.

Planned features include:

* 🌡 Temperature monitoring
* 💧 Humidity monitoring
* 📍 Live location tracking
* 🔒 Tamper detection
* 📲 QR/NFC-based traceability
* 📊 Real-time telemetry dashboard
* 🛡 Food safety monitoring during transport

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
